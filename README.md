# STOCKFLOW PRO
Multi-Warehouse Inventory Monitoring System.

## Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: SQLite demo (schema PostgreSQL-ready)
- Auth: JWT + RBAC

## Main Features
Multi warehouse, multi user, products, inventory, inbound/outbound, transfers,
stock adjustment, stock opname, DOI/ADS analytics, alerts, barcode field,
approval workflow, audit trail, CSV import/export.

## Demo login

## Run
### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev
